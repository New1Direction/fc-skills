description: Record chain activity and turn it into pool reports.
---

The Operator runs WATCHTOWER and a PULSE report worker together. One command starts capture, processing, and report generation.

## What it does

- Records included transactions and their receipts.
- Produces reports for the pools you configure.
- Recovers missing blocks and updates reports after chain changes.
- Shows progress, errors, and storage use.

## Try it locally

Requires Node.js 24 or newer. Run from the project folder:

```sh
node scripts/msk.mjs demo --out ../fc-operator-demo
```

This uses a simulated chain and stops when finished. It needs no wallet or provider key.

## Ready for live data?

You'll need three things:

| You need | Why |
| --- | --- |
| A Robinhood Chain data provider | Lets the Operator read blocks and receipts |
| A list of exact pools | Tells the report worker which pools to analyze |
| A running host with enough storage | Keeps capture and recovery available |

[Follow the setup instructions →](/docs/reference/operator-runbook/)

## Check a running workspace

Use the workspace path you chose during setup:

```sh
node scripts/msk.mjs status --workspace ../fc-robinhood
node scripts/msk.mjs reports --workspace ../fc-robinhood
node scripts/msk.mjs stop --workspace ../fc-robinhood
```

Reports are research observations. They do not place trades. The local demo has passed; a sustained 24-hour mainnet run has not yet been established.

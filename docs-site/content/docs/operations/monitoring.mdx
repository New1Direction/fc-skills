| Tool | Job |
| --- | --- |
| [WATCHTOWER](/docs/skills/watchtower/) | Records included transactions and checks their receipts |
| [PULSE](/docs/skills/pulse/) | Reads pool data and compares provider timing |
| [Operator](/docs/operations/operator/) | Runs capture and workers together, then saves pool reports |

## What counts as every transaction?

WATCHTOWER records the transactions reported in blocks by your selected provider, starting at the block you choose. Successful and reverted transactions are included.

Private pending activity and internal contract calls are outside that coverage.

## What happens if data is missed?

The tools track gaps and incomplete receipts. Recovery fills those gaps when the source provides the missing data.

If the chain replaces a block, affected reports are marked as no longer current. Earlier evidence is kept for review.

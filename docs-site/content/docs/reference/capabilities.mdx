## Native collection and analysis

| Skill | Native input or collector | Primary boundary |
| --- | --- | --- |
| Autopsy | Bounded standard ERC-20 transfer collection on EVM; retained evidence | Swap, liquidity, and wallet-control evidence need additional sources |
| Exit Doctor | Canonical 30-bps V2-style route | Does not establish V3, V4, or arbitrary-token support |
| Meme Scout | Retained social posts and token association evidence | No native live X/Grok collection |
| Ignition | Retained normalized swap windows | No native whole-chain discovery |
| Scout Network | Supplied historical wallet picks | No native complete live wallet collection |
| Second Wind | Retained historical and current participation windows | Requires a declared observation universe |
| LP Edge | Canonical Uniswap V3 positions and scenarios | No verified native V4 hook adapter |
| Undertow | Bounded Robinhood V4 collection and stock reference capture | Wallet-flow attribution is supplied; nonzero hooks remain unqualified for execution interpretation |
| PULSE | HTTP/WebSocket observations, optional raw feed capture, node probes | Provisional state is not an executable quote |
| HOOK LAB | Deployment, call/trace, and isolated Anvil evidence; Pons V2 fee model | Live source/runtime correspondence remains separate |
| PRESSURE | Bounded ERC-20 receipts, raw issuance, balances, multipliers | Liquidity comparisons require retained measurements |
| WATCHTOWER | Full RPC blocks and receipts over a declared interval | Internal traces and automatic skill execution are outside scope |
| CATALYST | Configured SEC issuer universe and bounded filing collection | Exact onchain identity mappings are supplied evidence |
| Night Desk | Bounded Robinhood REST references and corporate actions | Onchain marks and size-specific exit evidence are retained inputs |
| Agent Arena | Supplied portfolio, funding, and attempt history | No native complete wallet history or proof of agent authorship |
| CIRCUIT | Pinned Universal Router 2.1.1 V4 routes and isolated fork measurement | No live signing; current deployment correspondence needs verification |

## Three venue families

**Exit Doctor targets V2. LP Edge targets V3. HOOK LAB and CIRCUIT investigate exact V4 deployments and call paths.** Shared EVM compatibility does not make these adapters interchangeable.

A nonzero V4 hook can change fees, permissions, or state transitions. Retain evidence for the exact deployment and wallet call. A catalog entry or nominal ABI match is a starting point for investigation.

## Built, installed, and deployed

The package exports instructions, helpers, examples, and tests. Separately installed skill copies can diverge. Continuous services require a host, credentials, configuration, and operation. Application consumers require their own integration. No package skill signs or submits a live trade.

Consult the [release runbook](/docs/reference/release-runbook/) for recorded probes and validation limits.

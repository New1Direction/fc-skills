## v0.8.0 — CIRCUIT

The package contains 16 skills and 317 exported skill files. CIRCUIT adds exact Universal Router 2.1.1 V4 route construction, bounded path and cycle enumeration, Permit2 preflight, isolated Anvil measurement, and conditional Nitro fee estimates.

The release passes 1,422 offline tests, including 175 CIRCUIT checks. CIRCUIT also retains eight isolated scenarios against actual upstream Uniswap protocol bytecode. Those scenarios establish local protocol behavior with zero source writes. They do not establish a current Robinhood opportunity.

The fifteen earlier skill inventories remain byte-for-byte identical to v0.7.0. See the [full release runbook](/docs/reference/release-runbook/) for the retained service and adapter validation notes.

## Documentation addition

Fumadocs adds a searchable 16-skill catalog, runnable examples, quickstart instructions, workflow guides, operations notes, and evidence conventions. The README becomes the repository entry point. This documentation change does not alter the v0.8.0 skill inventory or deploy research services.

## Available now

- 16 research skills, each with instructions and examples.
- An Operator for capture, pool reports, and recovery.
- Searchable documentation and local demos.

## Verified locally

The package has 1,422 passing offline tests. The Operator adds 24 tests covering capture, reports, restarts, chain changes, and storage recovery.

These checks establish behavior against the tested inputs. They do not establish profitable signals or sustained mainnet performance.

## Still to establish

A working production data source, a persistent deployment, and a completed 24-hour mainnet run.

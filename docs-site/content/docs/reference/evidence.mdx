## Start with three checks

1. **Source:** Where did the data come from?
2. **Time:** When was it observed?
3. **Coverage:** What is included, and what is missing?

## Common labels

| Label | Meaning |
| --- | --- |
| Synthetic | Invented data used for a demo or test |
| Retained observation | Saved source data that can be reviewed again |
| Published example | An external example that may have incomplete history |
| Modeled | A calculation based on stated assumptions |
| Simulated | A transaction or scenario tested in a stated environment |
| Executed | A real submitted transaction with supporting records |

## Read unknowns literally

Missing costs are not zero costs. A displayed price is not a completed sale. A positive simulation is not realized profit.

Reports should keep those differences visible so you can decide what to investigate next.

## Compare like with like

Use the same assets, time window, position size, and cost basis. Keep unsuccessful cases and failed attempts in the record.

## Know what is running

The package contains research tools and deployable data services. Installing a skill does not start a service. Offline examples use synthetic or retained evidence. Continuous monitoring, live data credentials, application consumers, and live trade execution are separate work.

Use the [capability matrix](/docs/reference/capabilities/) before supplying a pool or route, and the [evidence guide](/docs/reference/evidence/) when interpreting results.

| --- | --- |

| Is buying interest spreading? | [Ignition](/docs/skills/ignition/) |
| Why did this stock-paired meme move? | [Undertow](/docs/skills/undertow/) |
| How would this swap route behave? | [CIRCUIT](/docs/skills/circuit/) |

## How it works

1. Choose a skill.
2. Give your agent a question and the available data.
3. Review the findings, sources, and missing information.

The tools produce research and simulations. They do not place live trades. Some skills read live sources; others need data you provide.

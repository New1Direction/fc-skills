## Work through three steps

1. **Check the data.** [PULSE](/docs/skills/pulse/) reads pool activity and compares sources. [WATCHTOWER](/docs/skills/watchtower/) records included transactions and receipts.
2. **Understand the pool.** [HOOK LAB](/docs/skills/hook-lab/) investigates custom fees and restrictions.
3. **Test the route.** [CIRCUIT](/docs/skills/circuit/) builds supported routes and measures wallet changes in a local simulation.

Include the trade size, wallet, pool identities, and block being tested. Fees and missing costs need to stay visible.

## Try an example

Requires Node.js 24 or newer. Run from the project folder:

```sh
node skills/circuit/scripts/circuit.mjs demo --out ../fc-route-demo
```

This uses sample identities. It does not find a live trading opportunity.

## Ask your agent

```text
Investigate this swap route with HOOK LAB and CIRCUIT.
Check the pool rules, required approvals, expected wallet changes, and costs.
Show any unsupported parts. Do not submit a live transaction.
```

A successful local simulation does not guarantee the same result on a live chain. [Read the route limits](/docs/skills/circuit/).

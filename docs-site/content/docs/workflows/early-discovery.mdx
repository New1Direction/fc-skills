## Follow four questions

| Question | Use |
| --- | --- |
| Is the meme spreading beyond a few accounts? | [Meme Scout](/docs/skills/meme-scout/) |
| Is buying interest broadening? | [Ignition](/docs/skills/ignition/) |
| Where did the launch supply go? | [Autopsy](/docs/skills/autopsy/) |
| What does the supported exit route show? | [Exit Doctor](/docs/skills/exit-doctor/) for V2; [HOOK LAB](/docs/skills/hook-lab/) and [CIRCUIT](/docs/skills/circuit/) for V4 |

For an older token coming back to life, add [Second Wind](/docs/skills/second-wind/). To review the wallet that found it, use [Scout Network](/docs/skills/scout-network/).

## Ask your agent

```text
Research this memecoin using the available data.
Check social attention, buying interest, launch supply, and exit support.
Show the strongest evidence, the reasons for caution, and what is missing.
```

Provide the token's contract address, chain, and time window. Add transaction records or saved social posts where available.

## Keep a useful record

Save the original report and revisit it later. Keep failed candidates and missing outcomes alongside successful ones. That makes later comparisons more useful.

Agreement between several tools is a reason to investigate further. It does not establish a probability of profit.

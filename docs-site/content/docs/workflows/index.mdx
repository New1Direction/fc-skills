These are research compositions. Except for the documented CATALYST-to-Night Desk JSON handoff, chaining the skills requires explicit input normalization and a consumer you operate. A WATCHTOWER dispatch record does not automatically invoke a skill or submit a trade.

## A useful handoff

Carry exact chain and contract identities, block numbers and hashes, observation times, data coverage, schema versions, and missing states into the next step. A ticker is a label; it is not an asset key. A displayed balance is not proof that a position can be sold at that value.

Use the [evidence guide](/docs/reference/evidence/) as the common reporting convention.

Start with a question, then use the next skill to check a different part of the picture.

<Cards>
  <Card title="Research a memecoin" href="/docs/workflows/early-discovery/">Check attention, buying interest, launch history, and liquidity.</Card>
  <Card title="Understand a stock token" href="/docs/workflows/fynch/">Connect company news, supply changes, and prices.</Card>
  <Card title="Investigate a swap route" href="/docs/workflows/arbitrage-ape/">Inspect pool rules and test a supported route.</Card>
</Cards>

These are research steps. Most handoffs need your agent to prepare the next skill's inputs. A named sequence does not start an automatic trading bot.

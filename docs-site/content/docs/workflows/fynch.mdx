## Look at each part separately

| Question | Use |
| --- | --- |
| What did the company disclose? | [CATALYST](/docs/skills/catalyst/) |
| Did the token supply change? | [PRESSURE](/docs/skills/pressure/) |
| Did a paired meme move because of the stock token? | [Undertow](/docs/skills/undertow/) |
| How do reference value and pool price compare? | [Night Desk](/docs/skills/night-desk/) |

Use the exact token address and observation time. A ticker alone can point to the wrong asset.

## Try a combined example

Requires Python 3.12 or newer. Run from the project folder:

```sh
python3 scripts/research_demo.py --out ../fc-stock-demo
```

The example connects a sample company filing to token valuation and portfolio reports. Open `../fc-stock-demo/research-bundle.json` to see the combined result.

It uses simulated data and does not update FYNCH or place trades.

## Ask your agent

```text
Review this stock token.
Separate company disclosures, token supply changes, and pool prices.
Explain what the data supports and whether the price references are fresh.
```

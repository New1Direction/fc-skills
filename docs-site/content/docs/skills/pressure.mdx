---
title: "PRESSURE"
description: "Reconcile stock-token issuance and compare retained trade-size liquidity observations."
---

Use it to investigate whether raw supply changed, where newly issued balances first went, and what matched execution measurements support.

**Runtime:** Node.js 24+.

## How it works

1. Pin a chain 4663 token and the (start, end] block window, with separate endpoint snapshots.
2. Collect bounded full receipts, raw supply, multiplier, code/decimals, and tracked balances; replay the retained transcript.
3. Reconcile mint/burn and tracked flows while reporting multiplier changes separately.
4. Compare matched retained liquidity observations and optionally freeze a prospective cohort with controls and missing outcomes.

## What to provide

- Exact token, endpoint block hashes, expected code/semantics, and a bounded collection request.
- Retained labels and tracked addresses for destination analysis.
- Optional wallet/route/size-specific liquidity observations and prospective outcome datasets.

## What you get

- Raw supply and balance reconciliation with mint recipients and observed destination categories.
- Separate multiplier accounting and explicit unmeasured holdings.
- Matched liquidity comparisons, joint reports, and outcome journals retaining controls and missing cases.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
node skills/pressure/scripts/pressure.mjs demo --out /tmp/msk-pressure-demo-new
```

This command was run successfully while preparing the documentation. Inspect the resulting directory before replacing the example inputs with your own evidence.

## Coverage and limits

- Collection is bounded to up to 64 intervening blocks, 256 receipts, and 20 tracked addresses.
- Aggregate custody is not sellable float or complete V4 pool inventory; fungible units cannot be tracked after mixing.
- Liquidity evidence is supplied; PRESSURE does not build route calldata or quote unsupported pools.
- A mint is not an automatic sell signal, and an ordinary wallet cannot assume issuer mint/redemption privileges.

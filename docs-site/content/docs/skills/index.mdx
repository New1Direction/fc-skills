Start with one skill. Each page explains what to provide and includes a prompt you can copy.

## Tokens and early interest

| Skill | What it helps you understand |
| --- | --- |
| [Autopsy](/docs/skills/autopsy/) | Where a token's launch supply went |
| [Meme Scout](/docs/skills/meme-scout/) | How a meme or narrative is spreading |
| [Ignition](/docs/skills/ignition/) | Whether buying interest is broadening |
| [Scout Network](/docs/skills/scout-network/) | Whether a wallet's early picks were followable |
| [Second Wind](/docs/skills/second-wind/) | Whether an inactive token is attracting new buyers |

## Liquidity and swaps

| Skill | What it helps you understand |
| --- | --- |
| [Exit Doctor](/docs/skills/exit-doctor/) | How position size affects an exit on supported V2 pools |
| [LP Edge](/docs/skills/lp-edge/) | Whether a V3 liquidity position beat holding the tokens |
| [HOOK LAB](/docs/skills/hook-lab/) | The custom rules and fees in a V4 pool |
| [CIRCUIT](/docs/skills/circuit/) | How a supported swap route behaves in simulation |

## Stock tokens

| Skill | What it helps you understand |

## Monitoring and performance

| Skill | What it helps you do |
| --- | --- |
| [PULSE](/docs/skills/pulse/) | Read chain data and compare provider speed |
| [WATCHTOWER](/docs/skills/watchtower/) | Record included transactions and recover gaps |
| [Agent Arena](/docs/skills/agent-arena/) | Review trading results after funding and costs |

V2, V3, and V4 are different pool designs. Support for one does not imply support for the others. [Check the support table](/docs/reference/capabilities/) when working with a real pool.

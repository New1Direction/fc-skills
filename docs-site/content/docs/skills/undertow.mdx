---
title: "Undertow"
description: "Explain stock-paired memecoin returns and observed participation on Robinhood Chain."
---

Use it to distinguish meme-relative movement from the stock quote, local token premiums, and corporate-action effects.

**Runtime:** Python 3.12+.

## How it works

1. Resolve exact chain 4663 token and V4 pool identities with aligned observations.
2. Decompose multiplicative return factors into meme/quote, local quote premium, and adjusted stock reference when available.
3. Aggregate retained wallet-attributed swaps, cancel intermediate route churn, and compare covered buyer cohorts.
4. Optionally collect bounded V4 receipt evidence and current stock references, then produce a combined report.

## What to provide

- Point-in-time meme/quote and local quote prices with exact units.
- Adjusted stock-reference evidence and contemporaneous multiplier when available.
- Retained attributed swap observations and a complete PoolKey/manager trust manifest for V4 collection.

## What you get

- Two- or three-factor return attribution with source and time qualification.
- Observed net participation and qualified rotation hypotheses.
- Shared quote-token relationships, component reports, hashes, and coverage gaps.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/undertow/scripts/research.py --attribution skills/undertow/examples/attribution.json --flows skills/undertow/examples/flows.json --out /tmp/msk-undertow-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- A V4 Swap sender or tx.from alone does not establish the beneficial trader.
- PoolManager custody is not one pool’s reserves; pool marks are not size-specific execution quotes.
- Current REST references require block-specific reconciliation before historical attribution.
- Relative performance is not causal alpha, shared quotes are not measured covariance, and V2/V3 adapters do not establish V4 support.

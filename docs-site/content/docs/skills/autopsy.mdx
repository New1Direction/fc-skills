---
title: "Autopsy"
description: "Reconstruct a token launch through its supply movements and transaction evidence."
---

Use it when a launch, deployer, allocation, or early wallet cluster needs an inspectable investigation.

**Runtime:** Python 3.12+.

## How it works

1. Pin the exact chain, contract, launch anchor, and block window.
2. Collect standard ERC-20 transfers, code, and limited metadata within bounded RPC budgets, or work from retained evidence.
3. Reconstruct event order and transfer flows; obtain supported swap, liquidity, trace, and funding observations separately.
4. Write facts, calculations, and hypotheses with source references, alternative explanations, and explicit coverage.

## What to provide

- Exact chain and contract or mint; question and observation window.
- Available RPC/explorer evidence or a retained native evidence packet.
- Opening/closing balances and verified token semantics for inventory claims; additional observations for swaps, liquidity, and relationships.

## What you get

- Ordered launch timeline and transfer-flow ledger.
- Supply allocation and wallet-relationship findings with competing explanations.
- Structured case report, evidence index, source hashes, and missing-coverage record.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/autopsy/scripts/case_tools.py ledger skills/autopsy/assets/training-case.json --out /tmp/msk-autopsy-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- The native collector supports standard EVM ERC-20 transfers; it does not natively decode every swap, pool, trace, token tax, or Solana instruction.
- Transfers into a router or pool do not by themselves establish buys or sales.
- Shared funding and timing do not prove wallet ownership; incomplete history cannot establish a first-ever event.
- Structural report checks and hashes do not authenticate provider truth or certify a token.

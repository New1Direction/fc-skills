---
title: "Ignition"
description: "Find broadening early buying participation across explicit observation windows."
---

Use it to build explainable traction shortlists and retain every candidate and later outcome.

**Runtime:** Python 3.12+.

## How it works

1. Freeze an exact token/quote universe, equal-duration windows, and knowledge cutoff.
2. Analyze retained normalized swaps with coverage and availability times.
3. Compare participation, buying expenditure, concentration, suspected activity, and relationship sensitivity.
4. Optionally append complete reports and later attributed outcomes to the signal journal.

## What to provide

- Normalized wallet-level swap observations with exact chain, token, quote, and venue identities.
- Coverage, event times, availability times, window definitions, and retained source references.
- Optional supplied relationship hypotheses and later follower-execution outcomes.

## What you get

- A complete candidate universe with pass, fail, and insufficient-evidence dispositions.
- Component traction measures and contrary evidence rather than an unexplained score.
- Append-only signal/outcome records with hashes, missing cases, and cost/execution basis.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/ignition/scripts/analyze_traction.py skills/ignition/assets/synthetic-traction.json --output /tmp/msk-ignition-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- No native full-chain discovery or independent decoding of upstream swaps is included.
- Buying expenditure is not net external capital; wallet counts do not prove independent people.
- Native analysis does not measure wallet retention, quote-adjusted momentum, or fair value.
- Engineering screens are uncalibrated; installation and one-time journal operations do not start monitoring.

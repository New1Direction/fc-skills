Use Ignition to compare buyer participation, spending, and concentration across time windows.

## What to provide

Saved swap records with token, wallet, pool, and time information. Include the periods to compare and any gaps in collection.

## Ask your agent

```text
Use Ignition to compare buying activity across these windows.
Show whether demand is becoming broader or more concentrated.
Flag missing data and evidence against the trend.
```

## What you get

A traction report showing changes in participation, spending, and concentration, with candidates for further research.

The tool analyzes supplied swap data. More wallets do not necessarily mean more people, and rising activity does not establish future returns.

<details>
<summary>Try a local example</summary>

**Runtime:** Python 3.12+.

Run from the repository root with a new output path. This example uses simulated data and makes no live network requests.

```sh
python3 skills/ignition/scripts/analyze_traction.py skills/ignition/assets/synthetic-traction.json --output ../fc-ignition-report-new.json
```

Open the output to explore the report before adding your own data.

<details>
<summary>Technical details and source</summary>

- No native full-chain discovery or independent decoding of upstream swaps is included.
- Buying expenditure is not net external capital; wallet counts do not prove independent people.
- Native analysis does not measure wallet retention, quote-adjusted momentum, or fair value.
- Engineering screens are uncalibrated; installation and one-time journal operations do not start monitoring.

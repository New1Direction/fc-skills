Use Night Desk to understand the gap between the underlying stock, the token’s onchain price, and available sale evidence.

## What to provide

The exact token, amount, timestamps, stock reference, and token adjustment data. Add pool prices, size-specific exit evidence, and costs if available.

## Ask your agent

```text
Use Night Desk to value this stock-token position.
Compare the adjusted stock reference, pool price, and exit evidence.
Show stale prices and missing costs.
```

## What you get

A side-by-side valuation with timestamps, price differences, and the limits of available exit evidence.

The tool can collect bounded stock references. It does not build swap routes, and a reference price is not a guaranteed sale price.

<details>
<summary>Technical details and source</summary>

- The collector makes at most four read-only Robinhood REST requests and creates reference evidence only.
- It does not collect wallet balances, build DEX routes, generate native quotes, or simulate arbitrary hooks.
- A reference midpoint is not a redeemable or executable price; API generation time is not exchange-tick freshness.
- Current multipliers cannot establish historical values, and USDG is not silently assumed to equal USD.

---
title: "Scout Network"
description: "Audit whether a discovery wallet\u2019s historical picks were realistically followable."
---

Use it to assess a scout watchlist without confusing insider allocations, eventual highs, or selected winners with repeatable discovery.

**Runtime:** Python 3.12+.

## How it works

1. Freeze a wallet cohort, eligible picks, decision cutoff, entry delay, budget, and exit policy.
2. Retain every eligible discovery, including losers, privileged access, failures, and unresolved outcomes.
3. Evaluate complete matured outcomes under the supplied follower scenario and separate connected activity.
4. Expose ranking gate failures, concentration, overlap, and sensitivity to separately specified scenarios.

## What to provide

- A complete declared wallet cohort and normalized discovery history.
- Point-in-time source evidence and ordinary-versus-privileged access classifications.
- Follower delay, trade size, exit policy, execution basis, and complete cost evidence.

## What you get

- Wallet-level sample sizes, all status denominators, exclusions, and coverage.
- Scenario-specific follower results with original-currency amounts and exact ratios.
- Qualified cohort comparisons or explicit reasons a ranking is unavailable.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/scout-network/scripts/evaluate.py skills/scout-network/examples/synthetic.json --output /tmp/msk-scout-network-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- There is no native live wallet collector.
- The helper validates supplied normalized data; it cannot authenticate complete upstream history.
- Famous winners chosen after the fact cannot become a validated scout cohort.
- Missing exits/costs stay unknown, and wallet relationships do not prove common ownership.

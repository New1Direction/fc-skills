---
title: "CATALYST"
description: "Connect retained SEC disclosures to exact Robinhood stock tokens and pools."
---

Use it for configured-company filing research, Form 4 interpretation, and measured local pool responses.

**Runtime:** Python 3.12+.

## How it works

1. Poll a bounded configured CIK universe with explicit dates, caller contact, and shared SEC request budget.
2. Retain original documents, hashes, document times, local receipt times, and parsing availability.
3. Parse non-derivative/derivative Form 4 rows, ownership, codes, footnotes, and amendment context.
4. Map exact security classes to verified chain/address identities and compare qualified retained pool observations.

## What to provide

- Configured issuer universe and an actual SEC contact User-Agent for live collection.
- Original ownership XML or retained filing documents.
- CIK plus precise security-title mapping evidence and exact pool observations with availability times.

## What you get

- Durable disclosure SQLite journal and retained original document evidence.
- Structured Form 4 events and exact-asset/pool associations.
- Measured local response reports with missing, late, conflicting, and orphaned cases visible.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/catalyst/scripts/catalyst.py demo --out /tmp/msk-catalyst-demo-new
```

This command was run successfully while preparing the documentation. Inspect the resulting directory before replacing the example inputs with your own evidence.

## Coverage and limits

- Native discovery covers configured issuers and bounded filings, not every EDGAR event or global catalyst.
- A newly detected Form 4 can report an older transaction; reported shares times price is not proven cash paid.
- A pool response is not evidence that the filing caused the move or created tradable excess return.
- No sentiment LLM connector, automatic onchain publisher, production background deployment, or trade executor is bundled.

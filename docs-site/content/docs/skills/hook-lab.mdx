---
title: "HOOK LAB"
description: "Investigate exact V4 hooks, deployment identity, fees, and wallet call paths."
---

Use it when a Robinhood pool has an unsupported hook or a route needs evidence about its exact code, configuration, and wallet behavior.

**Runtime:** Node.js 24+; Anvil for forks.

## How it works

1. Bind chain, block/hash, PoolKey, hook, router, dependencies, configuration, wallet, and calldata.
2. Inspect deployment identity and source-derived Pons V2 fee arithmetic where applicable.
3. Collect read-only calls/traces or complete balance changes in a disposable Anvil fork.
4. Check retained evidence consistency and compare code/configuration drift for the same exact case.

## What to provide

- Exact deployment and call JSON with block/hash and actual wallet context.
- Independent expected deployment/source/configuration evidence.
- Archive RPC access for reads; a separately installed trusted Anvil binary for fork measurements.

## What you get

- Identity, fee arithmetic, call/trace, and local-fork balance reports.
- Bound evidence qualification and observed deployment-drift results.
- Integration candidate evidence with explicit missing observations.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
node skills/hook-lab/scripts/hook-lab.mjs pons-fees --input skills/hook-lab/assets/pons-fees.synthetic.json --out /tmp/msk-hook-lab-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- Pons V2 here names the Pons hook family; it is not Exit Doctor’s Uniswap V2 AMM adapter.
- The Pons fee helper is not a full V4 traversal quoter or automatic build/runtime verification.
- Native positive qualification covers an exact direct two-asset swap, not an arbitrary size range or same-asset arbitrage.
- Published candidates and successful local checks do not establish a live mainnet route, audit, or consumer execution approval.

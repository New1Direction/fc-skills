---
title: "Agent Arena"
description: "Audit portfolio performance after external funding, open inventory, and failed attempts."
---

Use it to build inspectable agent scorecards from a complete declared evidence window.

**Runtime:** Python 3.12+.

## How it works

1. Freeze exact wallet scope, currency, window, snapshots, liabilities, and external cash flows.
2. Reconcile cashflow-adjusted PnL from complete NAV and retain failed, pending, and unattributed attempts.
3. Link exact time-weighted returns only when each funding event has qualified before/after valuation brackets.
4. Store append-only normalized evidence in a SQLite journal with conflict checks and content-chain verification.

## What to provide

- Complete retained portfolio snapshots, asset/liability marks, and external funding observations.
- All attempt evidence, including costs, failures, pending attempts, and any linked decisions.
- A frozen review header and raw source references.

## What you get

- Cashflow-adjusted PnL, qualified TWR or an unavailable reason, and snapshot-observed drawdown.
- Open inventory, unresolved attempts, cost evidence, and attribution gaps.
- Inspectable journal, export, integrity verification, and portable scorecard reports.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/agent-arena/scripts/arena.py analyze --input skills/agent-arena/assets/example.json --out /tmp/msk-agent-arena-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- No native complete live wallet collector or realized cost-basis ledger is bundled.
- Trading fees and failed gas must already be reflected in complete NAV; their informational breakdown is not subtracted twice.
- Missing marks/liabilities or funding brackets prevent complete NAV or exact TWR.
- Journal hashes do not prove complete history, authentic timestamps, agent authorship, or future skill; no public leaderboard is deployed.

---
title: "Second Wind"
description: "Investigate renewed participation in tokens with documented prior dormancy."
---

Use it when an established memecoin appears to be reviving and you need to distinguish new participation from a price bounce or incumbent activity.

**Runtime:** Python 3.12+.

## How it works

1. Resolve exact assets, pool scope, units, cutoff, and historical coverage.
2. Compare equal-duration active, subsequent dormant, and current windows using fixed dormancy criteria.
3. Measure newly observed versus returning buyers, spending concentration, incumbent selling, and usable liquidity.
4. Retain exclusions and competing explanations before assigning an evidence classification.

## What to provide

- Retained normalized observations for historical active, dormant, and current windows.
- Coverage and source references supporting buyer history and quote-unit liquidity.
- Fixed thresholds and explicit relationship coverage or hypotheses.

## What you get

- Documented dormancy and current activity change against the token’s own baseline.
- Buyer-cohort, concentration, incumbent-selling, and liquidity comparisons.
- A reproducible report with source kind, cutoff, hash, exclusions, and limitations.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/second-wind/scripts/analyze.py --input skills/second-wind/assets/synthetic-example.json --output /tmp/msk-second-wind-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- The bundled analyzer does not search live markets or provide an all-chain collector.
- Missing historical coverage cannot establish that a buyer is new.
- Migrations, rebases, or changed quote/token units need independent reconciliation; native comparisons reject these mismatches.
- A classification is not a revival probability or profit promise.

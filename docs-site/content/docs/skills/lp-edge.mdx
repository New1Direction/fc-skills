---
title: "LP Edge"
description: "Compare concentrated-liquidity fees, inventory changes, and costs against holding."
---

Use it to understand an existing V3 position or evaluate explicit range and price scenarios at equal starting assets.

**Runtime:** Python 3.12+.

## How it works

1. Pin the canonical V3 pool, NFT position, range, assets, block snapshots, and valuation units.
2. Separate remaining principal, accrued fees, prior owed balances, and removed-but-uncollected principal.
3. Compare interval assets against holding the same starting token quantities using matched prices and complete event coverage.
4. Evaluate supplied ranges and sampled price scenarios with explicit fee and operating-cost assumptions.

## What to provide

- Canonical V3 snapshot evidence or normalized historical-position/range inputs.
- Complete position-event continuity evidence for qualified interval comparisons.
- Token valuations, fee assumptions, operating costs, and optional wallet-call context.

## What you get

- Principal and fee accounting in both token units.
- LP-versus-holding results, inventory divergence, cost gaps, and fee hurdle.
- Range exposure, scenario sensitivity, and completed or missing wallet access checks.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/lp-edge/scripts/analyze_position.py skills/lp-edge/assets/synthetic-position.json --output /tmp/msk-lp-edge-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- Native collection and accounting target canonical Uniswap V3; V4 and hooks need verified external adapters.
- tokensOwed and collect proceeds may include principal and cannot automatically be called fee income.
- The range helper does not reconstruct hypothetical fills or fees from candles.
- Pool spot valuation is a mark, and missing costs leave net performance unknown.

Use LP Edge to see whether fees covered inventory changes and the costs of managing a liquidity position.

## What to provide

The V3 position, opening and closing balances, position events, token values, and operating costs.

## Ask your agent

```text
Use LP Edge to review this liquidity position.
Compare the result with holding the same starting tokens.
Show fees, inventory changes, costs, and missing data.
```

## What you get

A breakdown of fees, token balances, costs, and performance against holding the starting assets.

Built-in support targets standard Uniswap V3 pools. V4 positions need a verified adapter. Withdrawn principal must be separated from earned fees.

<details>
<summary>Try a local example</summary>

**Runtime:** Python 3.12+.

Run from the repository root with a new output path. This example uses simulated data and makes no live network requests.

```sh
python3 skills/lp-edge/scripts/analyze_position.py skills/lp-edge/assets/synthetic-position.json --output ../fc-lp-edge-report-new.json
```

Open the output to explore the report before adding your own data.

<details>
<summary>Technical details and source</summary>

- Native collection and accounting target canonical Uniswap V3; V4 and hooks need verified external adapters.
- tokensOwed and collect proceeds may include principal and cannot automatically be called fee income.
- The range helper does not reconstruct hypothetical fills or fees from candles.
- Pool spot valuation is a mark, and missing costs leave net performance unknown.

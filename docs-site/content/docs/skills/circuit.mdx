---
title: "CIRCUIT"
description: "Build exact V4 routes and measure complete wallet calls on isolated forks."
---

Use it to investigate route settlement, same-asset cycles, refunds, and explicit sampled trade sizes after supported costs.

**Runtime:** Node.js 24+; Anvil for forks.

## How it works

1. Compile one-to-four-hop exact-input routes against the pinned Universal Router 2.1.1 ABI using full PoolKeys.
2. Prepay input once, execute the path, and return all positive route-currency credits, including partial-fill refunds.
3. Read code, manager wiring, balances, and both existing Permit2 approval layers at the pinned parent block.
4. Simulate the exact ordinary-EOA wallet call in a disposable Anvil fork; reconcile balances and optional source fee estimates.
5. Enumerate bounded supplied paths/cycles and compare up to eight independent size samples from the same parent.

## What to provide

- Exact chain, parent block/hash/time, EOA, router, manager, Permit2, PoolKeys, and deployment evidence.
- Explicit raw input, minimum return, deadline, and any exact hookData.
- Archive source access and trusted Anvil for measured forks; retained fee/conversion assumptions for net estimates.

## What you get

- Unsigned compiled calldata and route validation.
- Preflight evidence, local receipts, wallet/router token changes, refunds, residuals, and retained failures.
- Conditional gas-adjusted accounting and sampled-size comparisons with excluded or unknown cases visible.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
node skills/circuit/scripts/circuit.mjs demo --out /tmp/msk-circuit-demo-new
```

This command was run successfully while preparing the documentation. Inspect the resulting directory before replacing the example inputs with your own evidence.

## Coverage and limits

- Compilation targets the pinned Universal Router 2.1.1 source ABI; live Robinhood runtime correspondence remains unverified.
- Native entry supports an ordinary EOA; contract wallets/vaults, flash borrowing, cross-chain legs, taxes, and rebases need other verified adapters.
- Nonzero hooks require exact investigation; a passing call does not establish generic hook safety.
- Anvil runs the next local block from the parent, not historical intrablock state or a proven Nitro equivalent.
- The tool does not seed live-wallet funding/approvals, sign permits, submit trades, or claim a sampled size is globally optimal.

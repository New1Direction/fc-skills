---
title: "Exit Doctor"
description: "Measure exits at explicit position sizes through a supported V2 pool."
---

Use it to compare displayed value with size-specific proceeds, price impact, additional costs, and execution evidence.

**Runtime:** Python 3.12+.

## How it works

1. Pin an exact router, factory, pair, token direction, and numeric block.
2. Collect reserves, balances, quotes, and optional wallet-call results for at most 20 explicit sizes.
3. Evaluate each size independently against the same starting state using exact 30-bps constant-product arithmetic.
4. Reconcile additional costs and apply stated prior-sale, liquidity-removal, or ordered buy/sell scenarios.

## What to provide

- Exact EVM route, token identities, target sizes, and pinned block.
- Native V2 evidence packet and optional wallet context.
- Optional complete additional-cost estimates and explicit hypothetical scenarios.

## What you get

- Independent size curve with output, defined impact metrics, and execution status.
- Separate modeled, router-quoted, and wallet-call-simulated results.
- Conditional net estimates, scenario results, and evidence/cost gaps.

## Run the offline example

Run from the repository root. This uses invented fixtures, makes no live network requests, and needs a fresh output path.

```sh
python3 skills/exit-doctor/scripts/analyze_exit.py skills/exit-doctor/assets/synthetic-evidence.json --costs skills/exit-doctor/assets/synthetic-costs.json --scenarios skills/exit-doctor/assets/synthetic-scenarios.json --max-impact-bps 500 --out /tmp/msk-exit-doctor-report-new.json
```

This command was run successfully while preparing the documentation. Inspect the resulting file before replacing the example inputs with your own evidence.

## Coverage and limits

- Native support is one canonical 30-bps Uniswap V2-style pool with standard-token assumptions.
- V3, V4 hooks, bonding curves, split routing, native wrapping, transfer taxes, and rebasing need verified external adapters.
- A router-call return is not a measured recipient balance change.
- Unknown additional costs leave net proceeds unknown; the largest passing tested size is not a global maximum or allocation recommendation.

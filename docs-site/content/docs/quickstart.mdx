title: Start here
description: Run an example, then choose your first skill.
---

## 1. Get the project

You'll need Git and Node.js 24 or newer.

```sh
git clone https://github.com/New1Direction/fc-skills.git
cd fc-skills
```

## 2. Try the demo

```sh
node scripts/msk.mjs demo --out ../fc-skills-demo
```

This runs a small simulated chain. It records transactions, creates pool reports, and updates them after a block changes.

No wallet, provider key, or npm install is needed. If the output folder already exists, choose a new name.

## 3. Read the result

Open `../fc-skills-demo/demo-report.json`. It shows the transaction count, report count, and recovery checks.

You can ask your agent:

```text
Read the demo report and explain what happened in plain English.
Point out which checks passed and what still needs real-world testing.
```

## 4. Choose a skill

[Browse the skills](/docs/skills/) and give your agent access to the complete folder for the one you choose. Its `SKILL.md` explains the task and required data.

Each skill page includes a prompt you can copy. Skills written in Python need Python 3.12 or newer; the page lists the requirement.

**For live monitoring:** follow [Run the Operator](/docs/operations/operator/). The demo does not start a permanent service.

# Application and worker handoff

Use WATCHTOWER/PULSE to retain exact pool identities and canonical changes. Preserve existing registry ownership. Build CIRCUIT input from relevant PoolKeys and parent hash. Enumeration covers only the supplied bounded registry, not complete chain opportunities.

HOOK LAB provides hook/source/configuration investigation. CIRCUIT adds Universal Router 2.1.1 calldata, payment preflight and complete-route accounting. Its copied HOOK LAB modules are self-contained; no sibling skill import is required.

Enqueue a `circuit.route.v1` or `circuit.sweep.v1` research job. A bounded worker with archive RPC and trusted Anvil runs `simulate`/`sweep`. Persist the entire result before UI summaries. Refresh or retract after a reorg, pool/hook/code change, wallet/approval change, expired deadline or stale fee estimate. Each sample gets a disposable fork; this is not a low-latency live execution engine.

Display candidate/simulation status, exact route/amount/wallet/context, balances, refunds, residuals, local gas, source fee estimate, conversion assumption and missing evidence. Positive estimated net is research evidence and must not automatically grant execution permission.

FYNCH/Ape need reviewed consumer mappings and actual caller-path integration. EOA simulation does not reproduce a vault call or remove its hook restrictions. No application changes, hosted endpoint, permanent worker or contract deployment is bundled.

Night Desk may consume exact size/route exit evidence if it preserves evidence kind and costs. Agent Arena may retain research attempts, but only actual executed portfolio changes count in live returns. Never record successful local simulations as live trades.
